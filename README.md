# Europe-1-100

Converts real-world terrain into a scaled-down version of itself in Minecraft. Includes a 1:100 scale map of Europe. 

Download: [![Planet Minecraft](https://img.shields.io/badge/Planet%20Minecraft-View%20Project-brightgreen)](https://www.planetminecraft.com/project/europe-1-100/) (3,000+ downloads, 19,000+ views)

How it works

1. Build the heightmap. Combines elevation data (GeoTIFF files), OpenStreetMap data, QGIS, and Paint.net automatic editing to produce a highly detailed heightmap of the terrain.
2. Import into WorldPainter. The heightmap is loaded into WorldPainter, then populated with real-world data like roads, biomes, and tree types from the OSM data.
3. Export. WorldPainter exports the finished region files, which become a complete, playable Minecraft world.

Programs used

QGIS, OpenStreetMap, heightmap data, Earth Tiles, WorldPainter
